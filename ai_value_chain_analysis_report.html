AIバリューチェーン分析

AI産業を構成する7つの領域に分け、 株価の動きと主要指数の関連性を比較する。 半導体から電力、クラウド、分析、セキュリティまで、 AIを支える産業構造を俯瞰します。

01 株価ダッシュボード

下のダッシュボードでは、期間を切り替えながら AI関連カテゴリーと主要指数の動きを比較できます。

1日・1週間・1ヶ月・年初来を切り替えて確認できます。

ダッシュボードを大きく表示 ↗

※表示に時間がかかる場合は、ダッシュボードを単独で開いてください。

02 分析の目的

AI関連株をひとまとめにしない

AI産業は、半導体だけで成立しているわけではありません。 データセンター、電力、クラウド基盤、データ分析、 セキュリティ、エンドユーザー向けサービスなど、 複数の領域が組み合わさってAIを支えています。

このダッシュボードでは、AI関連企業を7つのカテゴリーに分類し、 各カテゴリーの株価動向を比較できるようにしています。

また、S&P500、NASDAQ100、SOX、FANG+、POWR、NQCYBRを 比較対象に加え、指数ごとにどのカテゴリーとの関連性を 重視しているかをドットで表現しています。

03 AIバリューチェーンの7カテゴリー

各カテゴリーの企業は、分析用に選定した代表銘柄です。 すべての関連企業を網羅した一覧ではありません。

01 / ENERGY

エネルギー（電力）

AIの学習や推論、データセンターの稼働を支える 電力供給・電力インフラの領域です。

代表銘柄：CEG、GEV、VST
02 / SEMICONDUCTOR

半導体（チップ）

AIの学習や推論に必要な計算能力を提供する GPU、半導体設計、製造関連の領域です。

代表銘柄：NVDA、AMD、AVGO、TSM、ASML、ARM、MU
03 / DATA CENTER

データセンター（物理インフラ）

サーバー、設備、施設など、 AIシステムを物理的に稼働させるための基盤です。

代表銘柄：EQIX、DLR、SMCI
04 / CLOUD

クラウド（プラットフォーム）

AIモデルやアプリケーションを開発・運用するための クラウド基盤を提供する領域です。

代表銘柄：MSFT、AMZN、GOOGL、META
05 / ANALYSIS

分析（学習・差別化の源泉）

データ分析、AIを活用した意思決定、 データ基盤や分析ソフトウェアに関わる領域です。

代表銘柄：PLTR、SNOW、DDOG
06 / SECURITY

セキュリティ（安全性・信頼性の確保）

クラウドや企業システム、ネットワークを保護し、 安全なAI活用を支える領域です。

代表銘柄：PANW、CRWD、S
07 / SERVICE

サービス・アプリ（エンドユーザー）

AIを業務や日常のサービスに組み込み、 利用者に具体的な機能や価値を届ける領域です。

代表銘柄：NOW、ADBE、CRM

05 ドットマトリクスの見方

ドットの数は、カテゴリーとの関連度を表す設定値

ダッシュボード下部では、各指数と7カテゴリーの関係を ドットの数で表しています。

  • ドットが多い： 分析上、そのカテゴリーとの関連性を強く設定している。
  • ドットが少ない： 分析上、そのカテゴリーとの関連性を弱く設定している。
  • 緑色： 対象カテゴリーの表示期間中の変化率が0%以上。
  • 赤色： 対象カテゴリーの表示期間中の変化率が0%未満。

ドット数はプログラム内で指定した値であり、 市場データから自動計算された相関係数や構成比ではありません。

06 株価データの読み方

1日表示

前日終値を100とした基準で、 5分足データの変化を表示します。

1週間表示

取得期間の最初の値を100とし、 1時間足データの変化を比較します。

1ヶ月表示

直近約22営業日分のデータを使用し、 期間初値を100として比較します。

年初来表示

取得データのうち、当年のデータを使って 年初からの変化を比較します。

重要： カテゴリーの値は、選定した構成銘柄を時価総額で加重して算出しています。 指数の騰落率とカテゴリーの騰落率は、構成銘柄や計算方法が異なるため、 完全に同じ条件の比較ではありません。

07 分析上の注意点

  • 株価データはYahoo Finance経由で取得しており、 データの欠損や取得タイミングの違いが発生する場合があります。
  • 時価総額を取得できなかった銘柄は、 プログラム上の代替値を使用します。 その場合、加重平均の精度に影響する可能性があります。
  • カテゴリーは分析用に選定した銘柄群であり、 業界全体を代表するとは限りません。
  • ドット数は分析者が設定した分類上の目安であり、 統計的な相関関係を表すものではありません。
  • 過去の株価変動やカテゴリー間の同時変動は、 将来の値動きを保証するものではありません。

本ページは市場分析を目的とした情報提供であり、 特定の金融商品の売買を推奨するものではありません。

08 まとめ

AI関連株を分析するときは、半導体だけでなく、 電力、データセンター、クラウド、分析、セキュリティ、 サービス・アプリまで、産業全体を分けて考えることが重要です。

本ダッシュボードでは、7カテゴリーの株価変動と 6つの比較対象を並べることで、 AI関連市場のどの領域が相対的に強いか、弱いかを 観察するための材料を提供します。

期間を切り替えて短期と中期の動きを比較し、 単一の銘柄や指数だけでは見えにくい市場の変化を 多角的に確認するために活用できます。
